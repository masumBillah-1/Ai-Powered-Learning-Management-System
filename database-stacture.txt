Student, Instructor, Admin — সবাই একটাই collection এ থাকবে, শুধু role field আলাদা হবে।
কারণ:

Login, auth, profile — সব same logic
আলাদা করলে code duplicate হয়
Query করতে সহজ হয়


👤 Users Collection
jsusers: {
  _id,
  name,
  email,
  password,         // hashed
  phone,
  avatar,
  bio,
  role,             // "student" | "instructor" | "admin"
  isVerified,       // email verified?
  isBlocked,        // admin block করেছে?
  createdAt,
  updatedAt,

  // শুধু Instructor এর জন্য
  instructorInfo: {
    expertise,        // subject area
    rating,           // average rating
    totalStudents,    // count
    isApproved,       // admin approve করেছে?
    payoutMethod: {
      bankName,
      accountNumber,
      routingNumber
    }
  }
}

```
## সব Collections একসাথে
```
MongoDB/
├── users             # সবার জন্য একটাই (role দিয়ে আলাদা)
├── courses
├── enrollments
├── assignments
├── submissions
├── quizzes
├── quizResults
├── certificates
├── announcements
├── messages
├── transactions
└── payouts
```

## Relation Summary
```
users ──────────── courses (instructorId)

users ──────────── submissions (studentId)
quizzes ─────────── quizResults (quizId)
users ──────────── quizResults (studentId)
users ──────────── certificates (studentId)
courses ─────────── certificates (courseId)
users ──────────── transactions (studentId/instructorId)
users ──────────── payouts (instructorId)
