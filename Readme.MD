## 🛠 Technologies Used
- **React.js** — Frontend framework
- **Node.js & Express.js** — Backend server
- **MongoDB** — Database
- **Tailwind CSS** — Styling
- **OpenAI API** — AI-powered features
- **Firebase** — Authentication
- **Vercel** — Deployment

## ✨ Core Features
- 🤖 AI-powered course recommendations
- 📖 Interactive course management
- 👨‍🏫 Teacher & student dashboards
- 📝 Quiz and assignment system
- 📊 Progress tracking & analytics
- 🔐 Secure authentication system
- 📱 Fully responsive design

## 🚀 Run Locally

**Step 1:** Clone the repository
```bash
git clone https://github.com/masumBillah-1/Ai-Powered-Learning-Management-System.git
```

**Step 2:** Go into the project folder
```bash
cd Ai-Powered-Learning-Management-System
```

**Step 3:** Install dependencies
```bash
npm install
```

**Step 4:** Create `.env` file and add your environment variables
```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_API_URL=your_backend_url
VITE_OPENAI_API_KEY=your_openai_key
```

**Step 5:** Start the development server
```bash
npm run dev
```

**Step 6:** Open in browser
```
http://localhost:5173
```
